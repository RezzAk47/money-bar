# Security

Money Bar keeps your entries only in a local file and makes no network requests (see [README](README.md#privacy) and
[docs/DETAILS.md](docs/DETAILS.md#the-file-format-same-as-the-mac-app)). If you find a way it could write outside its data
folder or the CSV file you chose, or lose or leak your entries, please email rzk.karimi@gmail.com with steps to reproduce
instead of opening a public issue. Do not include your real data.

This is a one-person project: expect a reply within a few days, not hours. Only the latest version on `main` is supported.
